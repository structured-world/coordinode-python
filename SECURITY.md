# Security policy

## Archived packages

All versions of `coordinode`, `coordinode-embedded`, `langchain-coordinode`, and
`llama-index-graph-stores-coordinode` are unsupported. No further security fixes,
releases, or response-time commitments are provided. See the
[archival announcement](README.md#status-archived).

A vulnerability in the CoordiNode server itself belongs to the server
repository: <https://github.com/structured-world/coordinode/security>.
